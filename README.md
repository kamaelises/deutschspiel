# DeutschSpiel (public build)

Open: https://kamaelises.github.io/deutschspiel/

German A1 as a game: lessons, review, listening, games and the world Stillbach.
Progress is stored only in your own browser (IndexedDB/localStorage); there is no shared server.
The AI conversation (tutor) needs the author's PC and is available only in the full version.
Lesson videos are shown via the official YouTube player; no third-party videos are stored here.
